# تطبيق سطح المكتب — مكتب الأستاذ بوخاري مريم (موثق)

برنامج مكتبي مستقل (Desktop Application) يعمل بدون إنترنت (Offline 100%) لتحضير عقود **«إجراء إشهار عقاري»**.

---

## تشغيل البرنامج المباشر (EXE)

1. افتح مجلد `desktop_app/dist_executable/`.
2. اضغط مرتين على:
   ```text
   Ijraa_Ichhar_Notary.exe
   ```
   أو اضغط مباشرة على الملف المساعد: `تشغيل_البرنامج.bat`.

---

## تشغيل كود بايثون مباشرة (Tkinter Source)
يمكنك أيضاً تشغيل واجهة الـ Tkinter مباشرة من بايثون:
```bash
python desktop_app/main_gui.py
```

---

## مميزات البرنامج المكتبي:
1. **يعمل 100% بدون إنترنت وبدون الحاجة لتشغيل أي متصفح أو خادم**.
2. **واجهة رسومية عربية متكاملة**:
   - شريط كحلي أنيق مع ختم المكتب الدائري (`ب.م`).
   - استعراض واختيار ملفات Word (`.docx`).
   - استخراج تلقائي فوري لمراجع مسح الأراضي (القسم، البلدية، المجموعة الملكية، الولاية).
   - حقول إدخال وتعديل مراجع الإيداع والرسم.
   - نافذة حفظ واختيار مسار الملف الناتج في جهازك.
3. **تطبيق القواعد الدقيقة لعقد إشهار عقاري**:
   - إدراج العقد في الإطار الرسمي وحفظ الجداول مع تصغيرها إن كانت عريضة.
   - خطوط النهاية «-----» في أواخر الفقرات.
   - حماية الأرقام اللاتينية وتواريخ العقود ومسح الأسطر الفارغة.
