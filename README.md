# أدوات مكتب الأستاذ بوخاري مريم، موثق

تطبيق ويب داخلي رسمي لتحضير العقود التوثيقية بصيغة Word (.docx) باللغة العربية مع مراعاة كافة القواعد الرسمية.

## التشغيل السريع (Quick Start)

### 1. تشغيل الخادم فوراً:
فقط اضغط على تشغيل الملف `app.py`:
```bash
python app.py
```
افتح المتصفح على: `http://127.0.0.1:5000`

### 2. بيانات الدخول الافتراضية:
- **المستخدم**: `admin`
- **كلمة المرور**: `admin123`

### 3. إنشاء مسؤول جديد عبر سطر الأوامر:
```bash
flask create-admin <username> <password>
```

## هيكل المجلدات النظيف (Project Structure)
- **`app.py`**: نقطة البداية وتشغيل الخادم بضغطة زر واحدة.
- **`core_engine/`**: المحرك البرمجي لمعالجة ملفات Word و XML والجداول والذكاء الاصطناعي:
  - `ijraa_converter.py`: أداة «إجراء إشهار عقاري» (تصغير الجداول، فواصل الأسطر، الأرقام اللاتينية، مسح الأراضي).
  - `tables_builder.py`: أداة «عقد جدول الوصفي للتقسيم» (بناء جداول Word من قراءات الذكاء الاصطناعي مع فحص المجاميع وتلوين الخانات).
  - `detect_box.py`: الاستخراج الذكي التلقائي لمراجع مسح الأراضي (قسم، مجموعة، بلدية، ولاية).
  - `ai_reader.py`: قارئ الصفحات والمخططات باستخدام Claude ومكتبة PyMuPDF.
  - `job_queue.py`: إدارة المسح والمعالجة الخلفية للملفات الكبيرة مع شريط التقدم والإيقاف.
  - `models.py`: قاعدة بيانات المستخدمين وسجل النشاطات (Activity Log).
- **`routes/`**: مسارات التطبيق (تسجيل الدخول، لوحة التحكم، واجهات الأدوات، وإدارة المستخدمين).
- **`docx_templates/`**: القوالب الرسمية المعتمدة لملفات Word (`ijraa_ichhar_template` و `landscape_556_template`).
- **`templates/`**: قوالب HTML بالهوية البصرية الرسمية (شريط الحبر، ختم ج.م، التبديل بين اللغات والمظهر الليلي/النهاري).
- **`static/`**: ملفات التنسيق CSS والجافاسكريبت والأيقونات.
- **`tests/`**: اختبارات الجودة الأوتوماتيكية للتأكد من سلامة المحرك.
